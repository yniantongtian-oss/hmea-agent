# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x | Yes |
| Earlier snapshots | No |

## Report a vulnerability

Do not disclose a suspected vulnerability in a public issue.

Use [private vulnerability reporting](https://github.com/yniantongtian-oss/hmea-agent/security/advisories/new).
Include the affected version, impact, reproduction steps, and any known mitigation.

Maintainers should acknowledge a complete report within seven days. Acknowledgement is not a
promise that a report is valid or that a fix will be available on a specific date.
