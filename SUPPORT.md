# Support

Use [GitHub Discussions](https://github.com/yniantongtian-oss/hmea-agent/discussions) for setup
questions, experiment interpretation, and early ideas. Use
[GitHub Issues](https://github.com/yniantongtian-oss/hmea-agent/issues) for reproducible defects
and scoped feature proposals.

When asking for help, include:

- the command or smallest Python example that reproduces the behavior;
- the complete error output;
- the HMEA, Python, and NumPy versions;
- the operating system; and
- the expected result and the result you observed.

Machine-readable CLI output includes the HMEA and NumPy versions. Run `python --version` to add
the Python version.

Security reports must follow [SECURITY.md](SECURITY.md) instead of a public issue.
